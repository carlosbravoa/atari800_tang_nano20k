9. Keyboard

A standard USB keyboard becomes the Atari's keyboard: every key sits where an Atari key sits, and a handful of PC keys stand in for the Atari's function, console and Break keys.

How the keyboard reaches the machine

The board has no USB host of its own. Your USB keyboard plugs into a small adapter — a CH9350 USB-host module or a Raspberry Pi Pico — which sends the raw keyboard reports as CH9350 serial frames (115200 baud, 8N1) over a single data line to pin 53; the module itself takes 5 V and GND from the same header, so it is three wires in all. The frames are decoded in hardware inside the FPGA. Wiring and adapter setup are in Hardware setup. A keyboard is optional for browsing and mounting disks: a joystick on port 1 can drive the whole OSD menu on its own.

Mapping philosophy: your keyboard is an Atari keyboard

The PC keyboard is mapped to the Atari keyboard by position, not by the legends printed on the keys. Each physical key does what the key in the same place does on a real Atari XL keyboard. Letters, digits, the four rows of keys and the modifiers all line up, so touch-typing feels like the real machine. The difference shows in the symbols: the Atari puts its shifted symbols and its punctuation keys in different places from a PC, and here they are where the Atari has them.

Some consequences worth knowing:

  • Shift+2 types a double quote " (the Atari's Shift-2), not @.
  • Shift+8 types @ (the Atari's Shift-8), not *.
  • Shift+7 types an apostrophe ' and Shift+6 types &.
  • The two keys right of 0 (PC - and =) are the Atari < (Clear) and > (Insert) keys.
  • The two keys right of P (PC [ and ]) are the Atari − and = keys — the cursor-up and cursor-down keys when held with Ctrl.
  • The two keys right of L and ; (PC ' and \) are the Atari + and * keys — cursor-left and cursor-right with Ctrl. On an ISO keyboard the #/~ key next to Enter is the * key.
  • Square brackets are typed the Atari way: Shift+, gives [ and Shift+. gives ]. The colon is Shift+;.
Think Atari, not PCIf a symbol is not where you expect it, look at where it lives on an Atari XL keyboard and press that position. The key table below lists what every PC key becomes; the shifted symbols are then whatever the Atari prints on that key.

PC layout option (v3.1)

If you would rather have the keys type what is printed on them, set Options → Keyboard to PC (see Options). The mapping then follows a US-ANSI PC keyboard: letters, digits and most punctuation are unchanged, and the symbols that live under a different shift state on the Atari are translated for you, shift state included.

  • The real arrow keys still move the cursor in both modes. In PC mode the [ ] \ ' keys type their symbols instead of acting as the Atari's cursor keys.
  • {, }, ~ and ` have no Atari character; the grave key stays Break in both modes.
  • Control-key combinations (graphics characters) stay positional in both modes; F1–F12, console keys and the OSD keys are identical in both modes.
  • A key's symbol is decided when it goes down, so pressing Shift after a held key does not change what that key types. If two held keys need opposite shift states, the one needing Shift wins.
  • The setting is a US layout; a non-US physical keyboard gets the US-symbolic result. It is saved with kbdlayout= in atari.ini, and PC Link paste follows it automatically.

Special keys

  • Atari function keys F1–F4 are on F1–F4.
  • Help is on F5 and also on Insert.
  • Console keys: F6 = Start, F7 = Select, F8 = Option. Hold F8 during a boot where you would hold Option on a real machine.
  • Break is on the grave/tilde key ` (top-left, below Escape) and on Num Lock.
  • Inverse Video is on Right Alt.
  • Caps Lock is the Atari Caps key.
  • Cursor movement: the arrow keys move the cursor directly — on a real Atari the cursor keys are the − = + * keys held with Control, and the arrow keys supply that Control for you. Holding a real Ctrl as well changes nothing. The [ ] ' \ keys reach the same Atari keys but type the bare symbol; add Ctrl to move the cursor with them.
  • Hotkeys that never reach the Atari: F9 soft reset, F11 arrows/joystick toggle, F12 OSD menu. See The OSD menu for what Soft Reset does with a cartridge attached.
Inside the OSDWhile the menu is open, keyboard input is masked from the Atari: the keys navigate the menu and nothing is typed into the running program.

Arrow keys as joystick

For games that need a joystick when you only have a keyboard, the arrow keys can drive Joystick 1. In the OSD choose Options and set Arrow keys from NORMAL to JOYSTICK (see Options & atari.ini). While JOYSTICK is selected:

  • ↑ ↓ ← → move the stick on port 1, alongside any physical joystick wired to port 1;
  • Left Alt is the fire button;
  • the arrow keys are suppressed from the Atari keyboard, so they only move the stick and never type stray cursor movements;
  • everything else on the keyboard keeps working as normal.

Set it back to NORMAL to use the arrows as cursor keys again. The setting is written to atari.ini by Save changes (key joystick=, 0 = NORMAL, 1 = JOYSTICK; default 0) and survives reboots.

F11: flip it mid-gamePress F11 to switch arrows ↔ joystick live, without opening the OSD. F11 is a live-only switch: it is not saved, so the machine returns to the setting stored in atari.ini at the next boot.
