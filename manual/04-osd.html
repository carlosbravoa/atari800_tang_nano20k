4. The OSD menu

The on-screen display (OSD) is where you attach disks and cartridges, reboot the machine and change options — all while the Atari keeps running behind it.

Opening and closing the menu

The Atari boots first, with no menu shown. To open the OSD, press F12 on the keyboard or the onboard S2 button (the rightmost button on the Tang Nano). Either one opens and closes the menu, from any screen inside it. Esc (v3.1.1) closes it too: from a submenu it steps back to the main menu, from the main menu it closes the OSD, and with the OSD closed it remains the Atari's Escape key. The last main-menu item, 9) Return to Atari (Esc/F12), also closes it.

The Atari keeps running behind the menuWhile the OSD is open the machine is not paused: you will hear a game continue, and a disk load in progress carries on. Keyboard and joystick input is masked from the Atari while the menu is open, so moving around the menu does not play the game.
If the menu appears by itself at power-onThat is not normal. It means the machine did not auto-boot — usually because the OS or BASIC ROM could not be loaded from the SD card. See Troubleshooting.

Navigating

You can drive the whole OSD from a keyboard, from a DB9 joystick on port 1, or both:

Every submenu has a << Back entry, and the file browser has .. (or << Back at the top level). This is enough to boot games and mount disks with no keyboard attached at all.

The look

Since v3.0 the menu is drawn on a dimmed panel over the live Atari picture, so it stays readable over any game. The blue title bar names the current screen (TANG ATARI 800 on the main menu, with the firmware build date at the right), the footer bar reminds you of the keys (Up/Down move Enter select F12), and the selected row is a full-width blue bar. Pop-up messages are solid panels in the same blue.

ItemWhat it does
1) D1: / 2) D2:Show what is attached to disk drive 1 and 2 (None when empty; a read-only image is marked (RO)). Selecting one opens the drive menu.
3) Cart:Shows the attached cartridge (None when empty). Selecting it opens the cartridge menu.
4) Boot to OS (No BASIC)Reloads the OS and BASIC ROMs and cold-boots the Atari with the OPTION key held, so BASIC is disabled — the same as holding OPTION on a real XL. Use it to boot a DOS disk or a game disk that does not want BASIC in the way.
5) Boot to BASICReloads the ROMs and cold-boots into BASIC (OPTION not held).
6) Soft ResetA warm start — the same thing the RESET key does on a real Atari. F9 does this from inside a game without opening the menu.
7) Hard ResetA cold start: the machine restarts as if powered off and on, and the emulated cartridge is power-cycled too (see below). Also applies a changed RAM size.
8) OptionsOpens the Options screen.
9) Return to Atari (Esc/F12)Closes the menu. Esc, F12 and S2 do the same from anywhere (Esc goes back one level first when you are in a submenu).

Boot OS vs Boot BASIC — with a cartridge attached

Both Boot items reload the ROMs from the SD card and restart the machine cold. With a cartridge attached, both boot the cartridge — a real XL does the same, because the cartridge takes over the boot. Detach the cartridge if you want BASIC back.

The drive menu (D1: / D2:)

DISK DRIVE D1: MONTEZUMA.ATR 1) Attach (.atr/.xfd/.xex)... 2) New blank disk (90K) 3) Detach << Back
  • Attach (.atr/.xfd/.xex)... — opens the file browser filtered to disk images and executables. Picking an .atr or .xfd mounts it in this drive immediately, without rebooting: the Atari keeps running, and the new disk is simply there — swap disk 2 of a game in D1: when the game asks for it. If a disk was already in the drive it is replaced. Picking a .xex on D1: cold-boots straight into the program (see Executables).
  • New blank disk (90K) — creates a fresh, unformatted 90K single-density ATR in the root of the SD card, named BLANK01.ATR, BLANK02.ATR, … (the first free name up to 99), and mounts it in this drive. Format it from your DOS and you have a writable disk without touching a PC. The disk previously in the drive is detached. If all 99 names are taken the menu shows No free name.
  • Detach — removes the image from the drive, live, without a reboot. If the drive is empty you get Drive is empty.
  • << Back — return to the main menu.

Attaching and detaching disks never restarts the machine. To boot from the disk you attached, use 4) Boot to OS (No BASIC) from the main menu (Hard Reset boots with BASIC enabled, which most disks don't want) — see Disks.

The cartridge menu (Cart:)

CARTRIDGE Cart: None 1) Attach cartridge... 2) Detach << Back
  • Attach cartridge... — opens the file browser filtered to .car and .rom. As soon as a cartridge is loaded the Atari cold-boots straight into it and the menu closes. If the file is rejected (too large, unsupported type, bad size) a pop-up explains why and you stay in the browser.
  • Detach — removes the cartridge and cold-boots back to BASIC. With no cartridge attached you get No cartridge inserted.
  • << Back — return to the main menu.

Unlike disks, a cartridge change always restarts the machine — the cartridge is part of the memory map at boot. Details, formats and limits are in Cartridges.

The file browser

The browser opens at the root of the SD card. Its title bar reads ATTACH DISK or ATTACH CARTRIDGE depending on where you came from, with a page counter n/N at the right.

  • What is listed: folders (shown with a trailing /) and only the files that make sense in this context — .atr, .xfd and .xex for a drive, .car and .rom for the cartridge. Hidden and system files are skipped.
  • Folders: select a folder to enter it. The first entry, .., goes back to the parent folder; at the root it reads << Back and returns to the menu.
  • Pages: 24 entries per page. ←/→ (or stick left/right) flip pages immediately; moving ↓ past the last entry goes to the next page and ↑ past the first goes to the previous one.
  • Long names: long filenames are shown, truncated to 28 characters. Files can live anywhere on the card, in any folder.
  • Leaving: F12 or S2 returns to the main menu at any time.

If a disk image fails to mount, a short Mount failed line appears at the bottom of the browser and you can pick another file.

Pop-up messages

Errors and confirmations appear as a solid panel in the middle of the screen, for example Cartridge too large (>4MB), Unsupported CAR type 42 or Disk is read-only / Writes will fail (144). Press Enter or Fire to dismiss it and carry on.
