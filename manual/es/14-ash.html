14. ASH, el shell del Atari

ASH es un sistema operativo opcional para esta máquina: enciendes y llegas a una línea de comandos al estilo Unix en lugar de BASIC. Desde ahí recorres toda la tarjeta SD, montas discos, ejecutas programas y cartuchos, administras archivos, editas texto y, con el PC conectado, descargas archivos de internet y de servidores TNFS de FujiNet.

Activarlo (y desactivarlo)

  1. Copia ASH.CAR en la raíz de la tarjeta SD, con exactamente ese nombre. Descárgalo desde la página de versiones publicadas de ASH.
  2. Abre el OSD → Options → Boot → ASH → Save changes (guardar cambios).
  3. Apaga y vuelve a encender (o usa Hard Reset, reinicio en frío). La máquina arranca directamente en el shell:
ASH 1.3 TN - the Atari SHell
Type help for commands or basic to exit
D4:/$

Vuelve a poner Boot en BASIC para recuperar el clásico READY. Si ASH.CAR no está o está dañado, la máquina arranca BASIC como siempre, sin avisar. También puedes probar ASH sin cambiar la opción: Cart → Attach → ASH.CAR.

¿Por qué un cartucho? ASH se copia a la RAM en una fracción de segundo y luego desactiva el cartucho, así que los juegos ven una máquina normal con $A000–$BFFF libre. RESET siempre te devuelve al prompt.

El prompt

El indicador muestra dónde estás: D1:/–D4:/ son las unidades de disco, H:/ es la carpeta /HDD de la tarjeta SD y SD:/games es una carpeta cualquiera de la tarjeta SD. Cambia con cd, o escribe solo la unidad (d2:).

  • Tab completa nombres de archivo; ↑/↓ recuperan comandos anteriores; Ctrl+U borra la línea; Break cancela un comando.
  • Los nombres con espacios van entre comillas dobles: run "sd:/games/Candy Crunch.xex".
  • help muestra todos los comandos en una sola pantalla.

Explorar y ejecutar

ComandoQué hace
ls [-l] [path]Lista un directorio (* = programa ejecutable, / = carpeta)
cd path, pwdCambia / muestra el directorio actual: cd sd:/games, cd .., cd /
cat, xxd, fileMuestra un archivo de texto, un volcado hexadecimal, o qué es un archivo (en un .xex: sus segmentos)
run file, o solo el nombreCarga y ejecuta un programa: run sd:/games/pitstop.xex, o pitstop dentro de su carpeta

Discos, cartuchos y reinicio

ComandoQué hace
mountMuestra qué hay en D1:–D4:, la ranura de cartucho y el ajuste de arranque
mount d1: sd:/disks/x.atrPone una imagen de disco en una unidad (cualquiera, D1:–D4:)
umount d1:Vacía una unidad
cart sd:/carts/x.carCarga un cartucho y arranca con él. Desconéctalo desde el OSD (Detach) para volver a ASH (con Boot: ASH; si no, llegas a BASIC). Hard Reset reinicia el cartucho del juego, como al apagar y volver a encender.
rebootUn arranque en frío completo (se recargan las ROM y el cartucho se reinicia)
basic / exitSale de ASH a Atari BASIC; el comando DOS de BASIC vuelve a ASH

Administrar archivos

ASH reemplaza al DOS. Su dispositivo D: sigue disponible para BASIC y para los programas que inicies desde él (LOAD "D:GAME.BAS", guardar récords, etc.).

ComandoQué hace
cp src dstCopia entre discos, h: y la tarjeta SD; dst puede ser una carpeta
rm, mvBorra (con comodines en los discos: rm d1:*.bak), renombra o mueve
mkdir, rmdirCarpetas (en discos MyDOS y en la tarjeta SD)
lock, unlockProtege archivos en un disco
format d2:Borra un disco y lo deja como disco DOS 2 vacío (pregunta antes)
edit fileUn editor de texto a pantalla completa: Ctrl+S guarda, Ctrl+Q sale
lp fileImprime un archivo de texto (llega al PC, ver PC Link)

Los discos con escritura son de formato DOS 2 / MyDOS, de 720 sectores, densidad simple o doble; los discos más grandes son de solo lectura desde ASH.

Escribir en la tarjeta SD

La tarjeta SD es de solo lectura desde ASH por defecto. Escribe sd rw para permitir cp, mv, rm, mkdir y rmdir en sd: hasta el siguiente arranque en frío; sd ro lo vuelve a desactivar y sd muestra el estado. Incluso con la escritura activada, el firmware se niega a borrar o sobrescribir los archivos ROM, atari.ini, ASH.CAR y cualquier archivo que esté montado o adjuntado en ese momento.

Red, a través del PC

Con la placa conectada a un computador y ashterm corriendo ahí en modo interactivo (ver PC Link → ashterm), ASH puede usar la conexión a internet del PC. El Atari nunca habla con la red directamente: se lo pide al PC, que descarga el archivo y lo entrega por el enlace USB.

ComandoQué hace
dateLa fecha y hora del PC (después el Atari sigue contando; date sync vuelve a preguntar)
wget URL [dest]Descarga un archivo: a un disco, a h:, a la tarjeta SD (con sd rw), o - para mostrarlo
ls, cat, run, cpTambién aceptan URL http://, https:// y tnfs://
ls tnfs://tnfs.fujinet.online/ATARI
run tnfs://tnfs.fujinet.online/ATARI/_lobby.xex
cp tnfs://tnfs.fujinet.online/ATARI/games/x.atr sd:/disks/

TNFS es el protocolo de servidor de archivos que usa FujiNet; los servidores TNFS públicos tienen grandes bibliotecas de software que ASH recorre como si fueran un disco. Sin el programa del PC, estos comandos responden no answer from the pc; todo lo demás en ASH funciona sin PC.

Notas

  • Un programa que necesita un DOS específico (SpartaDOS, una llamada interna de DOS 2.x) puede no funcionar bajo ASH; en ese caso arranca ese DOS desde un disco.
  • La parte residente de ASH usa $0700–$1CFF (la misma zona que DOS 2.5), así que todo lo que carga bajo DOS carga bajo ASH.
  • ASH también existe como programa y disco de arranque (ASH-TN.XEX, ASH-TN.ATR), y en una edición genérica para cualquier Atari XL/XE (ASH.XEX, ASH.ATR), sin las funciones propias de esta placa.
