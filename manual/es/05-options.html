5. Opciones y atari.ini

La pantalla Options define las preferencias de entrada, video, audio, memoria y módem; "Save changes" las guarda en atari.ini en la tarjeta SD.

La pantalla Options

Abre el OSD (F12 o S2) y selecciona 8) Options (opciones).

OPTIONS << Return to main menu Arrow keys: NORMAL Scanlines: OFF H position: 0 <- -> Stereo: OFF RAM: 128 KB <- -> Modem (R:): OFF Keyboard: ATARI Save changes Up/Down move Enter select F12

Muévete con ↑/↓ y pulsa Enter (o Fire) para cambiar un ítem. Los dos ítems marcados con <- -> se cambian, en cambio, con ←/→ (o con la palanca del joystick). F12, S2 o << Return to main menu (volver al menú principal) te llevan de vuelta.

Cada cambio se aplica de inmediato para que puedas verlo u oírlo — salvo RAM, que necesita un arranque en frío — pero no se escribe nada en la tarjeta SD hasta que selecciones Save changes (guardar cambios).

Arrow keys

ValoresNORMAL (por defecto) / JOYSTICK
Se aplicaEn vivo
Clave inijoystick=0 / joystick=1

Con JOYSTICK, las teclas de flecha del teclado (Arrow keys) controlan el Joystick 1 (junto con cualquier joystick real conectado al puerto 1) y Left Alt es el botón de disparo. Esas teclas dejan entonces de llegar al teclado del Atari, para que no escriban caracteres sueltos. Vuelve a NORMAL para poder escribir de nuevo.

Cambio rápido: F11F11 alterna flechas ↔ joystick en vivo, en medio del juego, sin abrir el OSD. Es un cambio solo en vivo: nunca se guarda, así que en el siguiente arranque la opción vuelve a lo que diga atari.ini.

Scanlines

ValoresOFF (por defecto) / 25% / 50% / 75% — cada pulsación de Enter pasa al siguiente
Se aplicaEn vivo
Clave iniscanlines=0 … scanlines=3

Agrega a la imagen scanlines (líneas de barrido) oscuras al estilo de un monitor CRT, con la intensidad elegida. Ver Video.

H position

Valores0 (por defecto) a 48, con ←/→
Se aplicaEn vivo — la imagen se desplaza mientras mantienes pulsada la tecla
Clave inihpos=0 … hpos=48

Desplaza la imagen horizontalmente (H position = posición horizontal) para centrarla en tu pantalla. ← mueve la imagen hacia la izquierda (un número mayor), → la devuelve hacia la derecha. Pulsar Enter en este ítem no hace nada.

Stereo

ValoresOFF (por defecto, mono) / ON
Se aplicaEn vivo
Clave inistereo=0 / stereo=1

Activa la clásica ampliación estéreo de doble POKEY: un segundo POKEY en $D210, con el POKEY 1 en el canal izquierdo y el POKEY 2 en el derecho. Viene desactivada por defecto para que el software común no se vea afectado. Actívala antes de cargar software preparado para estéreo, o el segundo POKEY quedará en silencio. Ver Audio.

RAM

Valores128 KB (por defecto, 130XE) / 320 / 576 / 1088 KB (RAMBO) — se elige con ←/→
Se aplicaEn el arranque en frío que Enter ejecuta sobre este ítem (una máquina en marcha no puede cambiar su tamaño de RAM)
Clave iniram=128 / ram=320 / ram=576 / ram=1088

Elige el tamaño con ←/→ y luego pulsa Enter en la fila RAM: aparece el mensaje Rebooting with new RAM size... y el Atari arranca en frío con el nuevo tamaño. Recuerda seleccionar Save changes después si quieres que se conserve. Ver Ampliación de RAM.

Modem (R:)

ValoresOFF (por defecto) / ON
Se aplicaEn el siguiente arranque en frío
Clave inimodem=0 / modem=1

Soporte opcional del dispositivo serial R: (módem al estilo del 850) a través del cable USB-C, para que un programa de terminal como BobTerm pueda llamar a una BBS por telnet a través del PC. En OFF (por defecto) no tiene ningún efecto en el uso normal. Esta función está en desarrollo; ver PC Link y Problemas conocidos.

La opción Modem necesita dos archivos en la tarjeta SD que este proyecto no incluye: el handler 850 de Altirra y su relocalizador (obra de Avery Lee, redistribuida por el proyecto FujiNet). Descarga 850handler.bin (1281 bytes) y 850relocator.bin (341 bytes) del repositorio de firmware de FujiNet (data/webui/device_specific/BUILD_ATARI/) y colócalos en la tarjeta como /PC/850HAND.BIN y /PC/850REL.BIN, por ejemplo con atari.py send 850handler.bin PC/850HAND.BIN. El firmware se los entrega al Atari en el arranque en frío cuando Modem está en ON.

Keyboard

ValoresATARI (por defecto) / PC
Se aplicaEn vivo
Clave inikbdlayout=0 / kbdlayout=1

ATARI trata tu teclado como un teclado Atari según la posición de las teclas (el modo por defecto, descrito en Teclado). PC, en cambio, hace que cada tecla escriba lo que está impreso en un teclado de PC de EE. UU.: Shift+2 da @, la tecla de comillas da ' y ", las teclas de corchetes dan [ y ]. Se agregó en la v3.1; los detalles y la lista de diferencias están en Teclado → Opción de distribución PC. El texto pegado a través del PC Link sigue esta opción automáticamente.

Save changes y la marca "*"

En cuanto cambias algo, la última fila pasa a decir Save changes * — el asterisco significa que hay cambios que no se han escrito en la tarjeta SD. Selecciónala para escribir todas las opciones en /atari.ini; la fila muestra Options saved. y el asterisco desaparece. Si no se puede escribir en la tarjeta, aparece el aviso Cannot save options to SD.

Los cambios sin guardar son temporalesLos cambios que no guardes se mantienen solo durante la sesión actual. En el siguiente encendido (o cuando el reinicio por hardware con S1 vuelva a iniciar el firmware) se cargan de nuevo los valores de atari.ini.

El archivo atari.ini

El archivo está en /atari.ini, en la raíz de la tarjeta SD. El firmware lo crea la primera vez que seleccionas Save changes y lo marca como archivo oculto, así que puede que tengas que mostrar los archivos ocultos en tu PC para verlo. Es un archivo de texto plano con un key=value (clave=valor) por línea. Las líneas en blanco y las que empiezan con ;, # o [ se ignoran; las claves desconocidas también se ignoran. Cualquier otra línea sin un = hace que el firmware considere el archivo como corrupto.

Un archivo completo con los valores por defecto:

joystick=0
scanlines=0
hpos=0
stereo=0
modem=0
kbdlayout=0
ram=128
ClaveValoresOpción
joystick0 / 1Arrow keys NORMAL / JOYSTICK
scanlines0 – 3Scanlines OFF / 25% / 50% / 75%
hpos0 – 48H position (los valores fuera del rango se limitan al extremo más cercano)
stereo0 / 1Stereo OFF / ON
ram128 / 320 / 576 / 1088Tamaño de RAM (cualquier otro valor vuelve a 128)
modem0 / 1Modem (R:) OFF / ON

Si lo prefieres, puedes editar el archivo en un PC; se lee una sola vez cuando se enciende la placa. Si el archivo no existe, todas las opciones toman sus valores por defecto.
