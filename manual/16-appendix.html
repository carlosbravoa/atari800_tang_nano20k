A.3 File formats

FileMeaning
.atrDisk image with a 16-byte header. Single, enhanced and double density; both double-density layouts. Attaches to D1:/D2: from the OSD.
.xfdRaw, headerless disk dump. Density is detected from the file size. Attaches like an .atr.
.carCartridge image with a header that names the mapper type (table A.1). Up to 4 MB.
.romRaw cartridge dump without mapper information. Only 2/4/8/16 KB are accepted.
.xexAtari binary-load executable (multi-segment $FFFF/INITAD/RUNAD). Attached on D1: it cold-boots straight into the program with BASIC disabled; served through a baked-in loader as a virtual boot disk.
atari.iniSaved OSD options on the SD card, written by Options → Save changes: joystick=, scanlines=, hpos=, stereo=, ram=, modem=. See chapter 5.
HDD.ATRA disk image of that exact name in the SD card root; auto-mounted on D4: at every boot. MyDOS can format it up to 16 MB.

Joystick GND goes to any header GND; passive sticks need no +5 V. LED pins map to the board's silkscreen labels: 17 = LED2 (SIO data activity), 18 = LED3 (Atari booted), 19 = LED4 (SIO command frames), 20 = LED5 (heartbeat). Wiring details are in chapter 2.

A.5 Glossary

OSD
On-Screen Display: the machine's menu, drawn over the live Atari picture. Opened with F12 or the S2 button.
SIO
Serial Input/Output, the Atari's peripheral bus. Disks (D:) and the printer (P:) are SIO devices; here they are emulated by the firmware.
ATR
The common Atari disk-image file format: a 16-byte header followed by the sectors.
CAR
Cartridge-image file format: a header that identifies the bank-switching type, then the ROM data.
XEX
Atari DOS binary-load executable: segments with load addresses, optionally with INITAD/RUNAD run vectors.
ANTIC
The Atari's display-list processor; it fetches screen memory and builds the picture line by line.
GTIA
The Atari's colour and player/missile (sprite) chip; turns ANTIC's output into the final video.
POKEY
The sound, keyboard, paddle and serial-port chip. A second POKEY at $D210 gives stereo.
PIA
Peripheral Interface Adapter: the chip behind the joystick ports and, on XL/XE machines, memory-bank selection.
Genlock
Locking the video output's timing to the emulated machine's own timing, so the HDMI frame is exactly one Atari frame — no jitter or tearing, and no frame buffer.
RAMBO
A classic XL/XE memory-expansion scheme; the 320/576/1088 KB options use it.
MEMLO
OS pointer to the lowest free RAM address. Handlers such as H: and R: are installed above it and raise it; BASIC re-reads it on NEW.
CIO
Central Input/Output: the OS layer that programs use to talk to any device by name (E:, K:, P:, D:, H:…) with OPEN/GET/PUT/CLOSE.

A.6 Release history

  • v1.0 — first official release: a complete Atari 800/XL/XE on the board.
  • v1.1 — quality-of-life: second disk drive, friendlier menu and keyboard.
  • v2.0 — genlocked low-latency video, hardware SIO, .xex loading.
  • v2.1 — 4 MB cartridges and .xfd disk images.
  • v2.2 — dual-POKEY stereo, RAM up to 1088 KB, vertical centering fix.
  • v2.2.1 — OSD options persist across a power cycle.
  • v2.3 — on-screen SIO activity indicator; reliable .xex loading.
  • v2.3.1 — smooth fine scrolling in ANTIC mode 8 (accuracy fix).
  • v2.4 — disks you can actually write to; SD-card safety fixes.
  • v2.5 — PC Link over the board's own USB-C cable.
  • v2.5.1 — typing fix and the desktop app.
  • v2.6 — telemetry, remote debugging (status/screen/peek/poke) and the desktop app grows.
  • v2.7 — printer emulation (P:) with dot-matrix PDF.
  • v2.7.1 — cold boots no longer gamble (reliable cold-start sequence).
  • v2.8 — hard drive on D4:, the H: shared folder, MyDOS support.
  • v2.8.1 — PC Link reliability fix.
  • v2.9 — two-controller joysticks on header pins, F11 quick toggle, experimental BobTerm modem.
  • v2.9.1 — OSD menu cleanup (vestigial hot-key option removed).
  • v3.0 (built 2026-09-18) — redesigned OSD and cartridge power-cycle on Hard Reset.

Downloads and full notes: github.com/carlosbravoa/atari800_tang_nano20k/releases.
