12. RAM expansion

The machine starts as a 128 KB 130XE and can be expanded from the menu to 320, 576 or 1088 KB of RAMBO-style banked memory.

Available sizes

SettingWhat it is
128 KBA stock 130XE: 64 KB main memory plus 64 KB of extended memory. Default.
320 KBRAMBO-style expansion
576 KBRAMBO-style expansion
1088 KBRAMBO-style expansion — the largest available

The extra memory is banked RAMBO-style, like the well-known 320 KB / 576 KB / 1 MB upgrades for real XL/XE machines, so software written for those expansions can use it. Software that does not use extended memory is unaffected by the setting.

Changing the size

  1. Open the OSD (F12 or the S2 button) and choose Options.
  2. Move to the RAM line and use ← / → (or the joystick left/right) to pick 128, 320, 576 or 1088 KB.
  3. Press Enter (or Fire). Unlike the other options, a RAM change cannot be applied live: Enter cold-boots the Atari with the new size. Anything running is lost, so save your work first.
  4. To keep the size after the next power-up, choose Save changes. It is stored in atari.ini as ram= (128, 320, 576 or 1088; default 128). See Options & atari.ini.
RAM is the one option that needs a cold bootArrow keys, scanlines, H position, stereo and the modem all apply live. RAM takes effect only on the cold boot that the option performs when you press Enter.

Cartridges and RAM together

Every RAM size coexists with cartridges of any supported size, including the 4 MB MegaCart. You can run a 1088 KB machine with a 4 MB cartridge attached; there is no trade-off between the two.

Compatibility

Tried so far: demos that need expanded memory have been run at 320 KB and at 1088 KB, both correctly. 576 KB has not been exercised with expanded-memory software yet, but it is the same mechanism with a different bank count.
